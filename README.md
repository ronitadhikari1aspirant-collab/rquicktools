QuickTools

Everything You Need. One Place.

QuickTools is an all-in-one collection of useful digital utilities designed to make everyday tasks simpler.

Features

- QR Code Generator
- Word Counter
- Text Case Converter
- Percentage Calculator
- Age Calculator
- Unit Converter
- Text Reverser
- Image Resizer

Technology

- React
- TypeScript
- Vite
- CSS

Development

Install dependencies:

npm install

Start the development server:

npm run dev

Build for production:

npm run build

Project

QuickTools is designed for desktop, tablet and mobile devices, with light and dark themes.
