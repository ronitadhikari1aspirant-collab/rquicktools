## Project rules
- Tools are registered in `src/lib/tools.ts` (metadata) and `src/components/tools/index.ts` (component map); one shared `/tools/$slug` route renders them — keeps adding a tool to two edits.
- Pure tool logic lives in `src/lib/calc.ts` with tests in `calc.test.ts` — testable without UI.
- All tool processing runs in the browser; no backend — privacy and zero cost.
- Service worker is generated by vite-plugin-pwa and registered only from `src/lib/pwa.ts`, which refuses dev/preview hosts — prevents stale previews.
